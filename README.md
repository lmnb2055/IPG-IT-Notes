# IPG IT Notes

A practical knowledge base for documenting IT systems, processes, troubleshooting steps, and useful references.

## What belongs here

- How-to guides and repeatable procedures
- Troubleshooting notes and known solutions
- System, service, and environment documentation
- Configuration references and operational checklists
- Links to authoritative external documentation

## Suggested organization

Group notes by topic as the repository grows. For example:

```text
systems/       Services, applications, and infrastructure
procedures/    Repeatable operational workflows
troubleshooting/ Common problems and solutions
references/    Commands, links, and quick reference material
archive/       Outdated notes retained for context
```

Use clear filenames and prefer one focused topic per document. Add dates, version numbers, or environment details when they affect whether a note is still accurate.

## Writing guidelines

- Write for someone who did not create the original note.
- Include prerequisites, steps, expected results, and recovery steps where relevant.
- Record the source and date for information that may change.
- Keep sensitive credentials, secrets, and personal data out of this repository.
- Update or archive notes when procedures change.

## Contributing

Create a branch for substantial changes, add or update the relevant note, and review the rendered Markdown before merging. Small corrections and clarifications are encouraged.
