# Project 1: Endpoint Health Check (MGSE)

> **💡 Goal:** Review a small set of computers (operating system, sensor version, last seen, assigned policies) and write a short report of findings and items to investigate. This project is **read-only**: no policy changes, host containment or response commands until there is an approved lab.

**Learn:** Host inventory, filters, sensor coverage and policies.

**Process:**

1. Find each host record and record the operating system, sensor version and last-seen time.
2. Check its host groups and assigned policies, where visible.
3. Look for differences between the computers.
4. Write findings and questions, e.g. "This laptop hasn't checked in recently; is it retired or simply offline?"

> **💡 Reminder:** An old last-seen time is a lead to investigate. It doesn't by itself prove that a computer is unprotected.

## Findings

1. **Four hosts have not checked in recently** (as of 2026-10-22):

   | Hostname | Last seen | Days ago |
   | --- | --- | --- |
   | DALERANFT | 2026-09-14 | 38 |
   | DESKTOP-J0MTO4M | 2026-09-18 | 34 |
   | DESKTOP-U6PL8MF | 2026-09-23 | 29 |
   | RENEEADAMS | 2026-10-08 | 14 |

   DESKTOP-U6PL8MF was first and last seen on the same day, only about 2 hours apart.

2. **DALERANFT and DESKTOP-J0MTO4M share the same MAC address** (`c4-d6-d3-b1-64-33`). They are also two of the stale hosts. This may be one physical PC that was reimaged or renamed, leaving an old record behind, or the MAC could belong to a shared USB/dock network adapter.

3. **Sensor versions are mixed.** Five hosts run `7.22.19406.0` and five run `7.34.20610.0`, even though they all have the same `Windows Sensor Maintenance` policy. Some online hosts (DESKTOP-Q33DL22, BRYCE-LAPTOP, DESKTOP-13O6K9B) are still on 7.22.

4. **RENEEADAMS still runs Windows 10**, and its last user is `QA Lab`. Renee Adams now logs in to DESKTOP-Q33DL22, so RENEEADAMS may be an old PC that was reused for QA.

5. **No host has a grouping tag**, even though all 10 belong to MGSE. See [Missing Falcon Tags](../website/docs/🔐Security/crowdstrike-missing-tags.mdx).

6. **All hosts have the same policies.** The prevention policy is `ActiveWin` (a custom policy, assigned around 2026-09-09). The other policies are defaults.

7. **DESKTOP-18PM8NI's last user is `admin`**, a generic account rather than a named person.

---

## Questions

1. **What is `Default Policy (Windows, Linux, Mac)`?**
   It is the [host retention policy](https://falcon.us-2.crowdstrike.com/policies/host-retention/all/detail/d12324ca0dd7461a880feff419e2ab54/Settings). It controls how long inactive hosts stay visible in the console. A host gets a *default* policy when it is not in a host group assigned to a custom policy.

2. **Why are some last-seen dates so old?**
   - DALERANFT: offline
   - DESKTOP-J0MTO4M: offline
   - DESKTOP-U6PL8MF: ?
   - RENEEADAMS: ?

   Next step: ask the users (or check AD) whether each PC is retired, replaced or just powered off.

3. **Are DALERANFT and DESKTOP-J0MTO4M the same machine?** If so, can the old record be hidden?

4. **Why are some online hosts still on sensor 7.22?** What does `Windows Sensor Maintenance` actually set?

5. **What does the `No Token Protection` host group mean?** Does it turn off the uninstall/maintenance token for these PCs?
