# enteliWEB: Patch the PHP2Shell Vulnerability

For IT staff patching the enteliWEB server against PHP2Shell (ticket 25352).

> **⚠️ Critical vulnerability:** PHP2Shell (CVE-2026-109618, CVE-2026-109619) affects PHP and could let an attacker take control of a vulnerable system. enteliWEB runs on PHP, so its server must be patched.

## Vendor Notice (Summary)

| Item | What to do |
| --- | --- |
| enteliWEB 4.29 – 4.33 | Download **Patch PHP 4.29+**, extract it, and run `patch.bat` as administrator on the enteliWEB server. |
| enteliWEB below 4.29 | Update enteliWEB to 4.29 or later **first**, then apply the patch. |
| V4 devices (built-in web server) | No fix yet; the vendor is working on new firmware. Until then, **do not expose the control subnet to the Internet**. |

## Before You Start

Complete these steps first:

1. **Take a snapshot.** Sign in to ESXi at `172.16.86.114` and snapshot the enteliWEB VM before changing anything.
2. **Connect to the server.** Open Remote Desktop and sign in as `administrator`.
3. **Check the enteliWEB version.** It must be 4.29 – 4.33. If it is lower, update enteliWEB first.

## Steps

1. **Run the patch.** Download and extract **Patch PHP 4.29+**, then right-click `patch.bat` and choose **Run as administrator**.
2. **Verify enteliWEB.** Open enteliWEB and confirm it loads and works normally.
3. **Clean up.** Once everything works, delete the snapshot (snapshots slow the VM down if left in place).

**Rollback:** If enteliWEB breaks after the patch, revert the VM to the snapshot you took before starting.

Update ticket 25352 with the result and reply to the vendor if anything failed.
