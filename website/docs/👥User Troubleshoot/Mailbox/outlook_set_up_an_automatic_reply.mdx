# Outlook: Set Up an Automatic Reply (as IT Admin)

How to set an out-of-office reply on another user's mailbox.

> **💡 Good to know:** Users normally set their own automatic replies in Outlook. IT sets one for them when the person is already out and unreachable, has left the company, or for a shared mailbox with no day-to-day owner. The reply is set on the mailbox, so it applies no matter which app the user signs in from.

> **⚠️ Confirm with the user or their manager first.** The reply goes out under their name to everyone who writes to them.

## Steps

1. Go to the [Microsoft 365 admin center](https://admin.microsoft.com) → **Users** → **Active users** and select the user.
2. Open **Mail** → **Automatic replies**.
3. Turn on automatic replies and enter the message.
4. Set the date range. Without an end date, the reply keeps running until someone turns it off.
5. Click **Save**.

**Expected result:** A test message sent to the mailbox returns the automatic reply.

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| Sender only receives the reply once | Normal. Exchange sends one reply per sender per period. |
| Absence not showing on the team calendar | An automatic reply isn't a calendar entry. Book the absence as an event. |
| Shared mailbox reply not firing | Set it on the shared mailbox itself, not on a delegate's account. |
| **Automatic replies** option not visible | Your role isn't active. Activate your admin role in PIM. |
| Reply still running after the user returns | No end date was set. Turn it off manually. |
