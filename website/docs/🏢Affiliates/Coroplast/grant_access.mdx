# Coroplast: Grant Access to a SharePoint Site

How to give a user access to a Coroplast SharePoint site by adding them as a guest and assigning them to the right site group.

> **💡 Good to know:** Coroplast builds on its own SharePoint, managed with the `admin@coroplast.com` account. Access takes two parts: add the user to the site as a **guest**, then add them to the **group** that grants the permissions they need.

**Example:** Lucy Dai needed access to the **Corrugated Plastic - Analysis** site. She was added as a guest and then put in the **Profile Analysis** group.

## Before You Start

1. Check which team the user is on (for example, Serene (Szu-Hui) Chen's team). This tells you which site and group they need.

## Step 1: Add the User as a Guest

1. Go to Coroplast's SharePoint and sign in (or switch) to `admin@coroplast.com`.
2. Open the SharePoint site (e.g. **Corrugated Plastic - Analysis**).
3. Select **Add users**.
4. Add the user as a **Guest**.

## Step 2: Add the User to the Site Group

1. Open **Settings** → **Site permissions**.
2. Go to **Coroplast** → **Groups**.
3. Open the group (e.g. **Profile Analysis**).
4. Select **New** → **Add a user**, and add the user.

**Expected result:** The user appears as a member of the group and can open the site and its content. Confirm with the user before closing the ticket.
