# Meraki VPN: Check and Set Up a User's VPN Access

How to check a user's VPN access in Meraki and configure the VPN connection on their computer.

> **💡 Good to know:** Each user connects to their plant's VPN using that plant's server address. Setup has three parts: check their account in Meraki, configure the VPN connection, and give them a clearly named shortcut.

## Before You Start

Have these ready:

1. The user's assigned plant.
2. The plant's VPN server address.
3. Access to the plant's Meraki Client VPN settings.
4. The user's VPN username and required connection settings.

> **ℹ️ Note:** Confirm whether "use their IP" means the plant's public VPN address or an IP address used to identify the user's plant.

## Step 1: Check the User's VPN Access in Meraki

1. Identify the user's assigned plant.
2. Open **IT** → **Meraki**.
3. Select the user's plant.
4. Open **Client VPN** → **User Management**.
5. Find the user's account and act on its status:

| Account status | Action |
| --- | --- |
| User exists and can sign in | Continue to [Step 2](#step-2-configure-the-vpn-connection). |
| Forgot their password, or password expired | Follow the approved password recovery process. *(Recovery steps still to be added.)* |
| User does not exist | Select **Add user**, enter the required details, and set **VPN authorization** to **Yes**. *(Confirm the exact field label.)* |

**Expected result:** The user has an account authorized to connect to the plant's VPN.

## Step 2: Configure the VPN Connection

Follow [VPN: Install a Plant VPN Connection](./Install_Plant_VPN.mdx) to create the connection on the user's laptop, add the **VPN** shortcut, and sign in with these credentials.
