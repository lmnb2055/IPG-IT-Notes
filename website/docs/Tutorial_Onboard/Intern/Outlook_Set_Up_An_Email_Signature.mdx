# Outlook: Set Up an Email Signature

How to create an email signature in new Outlook or Outlook on the web.

> **💡 Good to know:** Signatures are set per mailbox in Outlook's settings, not deployed centrally. Classic Outlook stores signatures separately, so anyone who switches between classic and new Outlook needs to set it up in both.

## Steps

1. Open Outlook.
2. Click the ⚙️ **Settings** icon in the upper-right corner.
3. Select **Accounts** → **Signatures**.
4. Click **+ New signature**.
5. Enter a name for the signature.
6. Type or paste the signature into the editor. Corporate logos are available from **Corporate Logos**.
7. Choose whether to apply it automatically to:
   - New messages
   - Replies and forwards
8. Click **Save**.

> **Note:** If you have more than one signature, the dropdowns in step 7 set the defaults. You can still switch signatures manually for each message.
