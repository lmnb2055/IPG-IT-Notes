# Travel Request: Add Users to Travel Whitelist

How to whitelist a user who will be signing in while traveling.

> **💡 Good to know:** The [Travel Request list](https://fpcusa.sharepoint.com/sites/Inteplast/Lists/Travel%20Request/AllItems.aspx) on SharePoint is the travel whitelist. Adding a user with a date range allows their sign-ins during that window instead of blocking them as unusual activity. Add the entry **before the user departs**. Access ends automatically when the date range is over.

## Steps

1. Open the [Travel Request list](https://fpcusa.sharepoint.com/sites/Inteplast/Lists/Travel%20Request/AllItems.aspx).
2. Get the user's **full name** and **travel date range** from their request.
3. Click **+ New**.
4. Fill in the user's details and the date range.
5. Click **Save**, then confirm the status shows as **active**.

**Expected result:** The entry appears in the list with the correct date range and an active status.
