# IT Tools: Onboarding Guide

Welcome to the IT team! This page lists the tools you'll use day to day, what each one is for, and the links worth bookmarking.

:::tip[Daily habit]

At the start of **every shift**, activate your required PIM roles in [Azure My Roles](https://portal.azure.com/#view/Microsoft_Azure_PIMCommon/ActivationMenuBlade/~/aadmigratedroles). Many admin tools won't work until you do.

:::


## Before You Start

Complete these steps first:

1. Follow the process on [Helpdesk Onboard](https://helpdesk.inteplast.com/onboarding).
2. Set up your business email.
3. Configure MFA with Microsoft Authenticator.
