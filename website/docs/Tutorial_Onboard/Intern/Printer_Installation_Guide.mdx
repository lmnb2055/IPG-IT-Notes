# Printer: Installation Guide

How to connect a user to a network printer from the HQ print server.

> **💡 Good to know:** Printers are published on `\\fuhqnts4z.fuhq.home.usa`. Browsing to that path shows every shared printer. Double-clicking one installs the driver and adds it to the user's device automatically.

## Before You Start

The device must be on the corporate network or connected to VPN.

## Steps

1. Open **File Explorer**.
2. In the address bar, type `\\fuhqnts4z.fuhq.home.usa` and press **Enter**.
3. Find the printer the user needs in the list.
4. Double-click it to install.
5. Print a test page to confirm.
6. If it should be their default printer, set it in **Settings** → **Bluetooth & devices** → **Printers & scanners**.

**Expected result:** The printer appears under **Printers & scanners** and the test page prints.
