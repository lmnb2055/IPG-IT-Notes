# AI Tools: Add a Seat for a New Member

How to add a user to the Claude and ChatGPT team plans.

> **💡 Good to know:** Claude and ChatGPT are both licensed per seat, so every new member costs the team. Access is granted by invitation from the admin console, and the process is nearly identical in both tools.

> **⚠️ Do not start without approval from the user's supervisor.** Email approval is fine. Keep it with the ticket as the record.

## Steps

1. Sign in to Claude or ChatGPT as an admin.
2. Click the user menu in the lower-left corner.
3. Open **Members**.
4. Select **Add member** and enter the user's email address.
5. Verify the name and email are correct before sending the invite.
6. If the user needs both tools, repeat these steps in the other one.

**Expected result:** The user appears in the member list as invited and receives an invitation email.

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| Invite never arrives | Check spam, then confirm the address. A typo invites nobody but still holds a seat. |
| **Add member** unavailable | You're not an admin on that workspace. |
| User already listed | They may have signed up with a personal account. Remove them and re-invite with their corporate address. |
