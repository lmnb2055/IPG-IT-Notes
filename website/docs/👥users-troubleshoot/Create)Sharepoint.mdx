# SharePoint: Create a Shared Site for a Plant

How to set up a SharePoint site when a plant asks for a shared drive.

> **💡 Good to know:** OneDrive is for one person's files. When a team needs a shared place for files, create a SharePoint site for them instead.

## Example Request

> **Ticket 25343** (`@bssj.inteplast.com`): "Is there any specific shared drive New Jersey IT requires us to use? Or can we simply use Microsoft OneDrive that is already available on our PCs?"

**Answer:** Don't use personal OneDrive for shared files. IT will create a SharePoint site for the team.

## Steps

1. Sign in to the [Microsoft 365 admin center](https://admin.microsoft.com) as `admin@bsjk.inteplast.com`.
2. Go to **Admin centers** > **SharePoint**.
3. Open **Sites** > **Active sites**, then select **Create**.
4. Choose **Team site** and fill in:
   - **Site name:** the plant or department name
   - **Owner:** the requester or their supervisor
   - **Privacy:** Private
5. Select **Finish**, then add the team members to the site.
6. Send the site link to the requester and close the ticket.

**Expected result:** The site appears under **Active sites**, and the team can open it and upload files.
