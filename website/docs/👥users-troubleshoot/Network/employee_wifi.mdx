# Reset a User's Password

Three ways to reset a user's password. They behave differently, so pick one based on whether the user needs a specific password or a temporary one.

> **💡 Good to know:** The Microsoft 365 admin center and Intune both write to the same Entra ID account, but the outcome differs. The M365 admin center lets you set a specific password. Intune generates a temporary password that the user must change at next sign-in.

## Which Option to Use

| Option | Use when | Result |
| --- | --- | --- |
| [1. Microsoft 365 admin center](#option-1-microsoft-365-admin-center) | You need to set a specific password | Password you choose |
| [2. Intune](#option-2-intune-temporary-password) | A temporary password is fine | Temporary password; user sets their own at next sign-in |
| [3. Active Directory](#option-3-active-directory) | The account is locked or managed in on-premises AD | Unlock status checked in AD |

## Before You Start

- **Verify the user's identity** before resetting anything.
- Plan to **give the new password by phone**.

## Option 1: Microsoft 365 admin center

1. Open the [Microsoft 365 admin center](https://admin.cloud.microsoft/#/homepage).
2. Go to **Users** → **Active users**.
3. Search for the user.
4. Click **Reset password** and enter the password you want to set.

## Option 2: Intune (temporary password)

1. Open the [Microsoft Intune admin center](https://intune.microsoft.com/#home).
2. Go to **Users** and search for the user.
3. Click **Reset password**. A temporary password is generated.

> **Note:** The user is prompted to set their own password the first time they sign in.

## Option 3: Active Directory

1. Open **Active Directory**.
2. Go to **Users** and search for the user.
3. Check the account's lock status and unlock it if needed.

## After the Reset

1. Confirm the user can sign in and reach mail and other SSO apps before closing the ticket.
2. If the reset was for security reasons (for example, a compromised account), also **revoke the user's sessions** and have them **re-register MFA**.
