# Laptop: Retrieve Local Administrator Password (LAPS)

How to get the local admin password for a managed device when a user needs elevated rights to install updates or make local changes.

> **💡 Good to know:** Intune stores a rotating local administrator password for each enrolled device (LAPS). When a user hits a task that needs local admin, such as a driver update or software install, you retrieve the current password and sign in locally instead of giving the user permanent admin rights.

> **⚠️ The password rotates after use.** Retrieve it when you need it. Don't save it or reuse an old one.

## Steps

### 1. Retrieve the password

1. Open the [Microsoft Intune admin center](https://intune.microsoft.com/#home).
2. Go to **Users** and search for the user.
3. Open **Devices** and click the device in question.
4. Select **Local administrator password recovery**.
5. Click **Show local administrator password**.

### 2. Sign in on the device

When Windows asks for administrator credentials, enter:

| Field | Value |
| --- | --- |
| Account | `.\localadmin` |
| Password | The password you just retrieved |

**Expected result:** The local account signs in with administrator rights, and the user can complete the update or install.
